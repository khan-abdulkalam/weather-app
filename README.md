
# 🌤️ Weather App

A modern, responsive weather dashboard designed to provide a clean and interactive weather experience. Explore weather information for popular cities with a beautiful UI, useful weather insights, and personalized features.

## ✨ Features

- 🌍 Search weather by city
- 🌡️ Celsius and Fahrenheit temperature units
- 🌙 Dark and Light mode
- 📍 Popular city shortcuts
- ⭐ Save favorite cities
- 🕘 Recent search history
- 🌦️ Current weather dashboard
- 📊 Weather metrics including humidity, wind speed, UV index, pressure, and visibility
- ⏰ Hourly weather forecast
- 📅 5-day forecast
- 💡 Smart weather and comfort recommendations
- 🌫️ Air quality information
- 🎒 Smart packing checklist
- 📱 Fully responsive design
- 💾 LocalStorage support for saved preferences

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Responsive Web Design

## 🎨 Design

- Modern dark-themed interface
- Glassmorphism-inspired UI
- Smooth animations and transitions
- Clean dashboard layout
- Mobile-friendly experience
